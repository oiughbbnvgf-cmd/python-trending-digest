🔍 生态趋势

1. Agent 工具链是本期绝对主线，占 4/10 且包揽增速榜

treg（#1，4.5×）、experiential（#9，16.7×）、i-have-adhd（#5，1.1×）、financial-services（#4）——十个位置里四个在做「让 agent 更好用」的基础设施：统一网关、模型路由、输出纪律、行业模板。增速最高的两名（16.7× 和 4.5×）都在这一类。

2. 「降低门槛」和「抬高门槛」是同一股力量的两面

一边是 Soup（4GB 显存训 8B）、minimind（两小时训 64M）、VoiceStudio（本地替代 SaaS），都在把门槛往下压；另一边是 microduck_rl 必须 CUDA GPU、minimind 参考环境要 8×RTX 3090。有意思的是门槛低的那些降的是「上手」门槛，高的那些降的是「知识」门槛而非硬件门槛——硬件门槛本身不降反升。

3. 中位增速 1.2× 说明榜单已进入沉淀期

10 个项目的增速倍数中位数只有 1.2×。本期有 4 个项目指数 > 60%（真正新项目），但同时 3 个项目指数 < 25%（financial-services 9%、minimind 13%、timesfm 17%），它们是已沉淀的常青项目。月榜正在变成「新项目爆发 + 老项目常驻」的混合结构，不再是一次性流量。

总结：这一期的 Python 生态，钱和注意力都在流向 agent 的「中间层」——路由、网关、模板、输出纪律；而硬件密集型研究（机器人 RL）依然只在极小的圈子里流通。选型的真实分水岭是门槛，不是热度：10 个项目里能零成本跑通的只有 2 个，其余要么要 GPU、要么要自己扛环境。
